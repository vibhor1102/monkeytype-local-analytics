# Report a security problem

Please [report a vulnerability privately on GitHub](https://github.com/vibhor1102/monkeytype-local-analytics/security/advisories/new) if it could expose data or let a website misuse the extension.

Include the affected version, clear steps to reproduce the problem, and the possible impact. Use a small example rather than your real typing history. Don’t include passwords, browser profiles, or private backup files.

For ordinary bugs and feature ideas, use [GitHub Issues](https://github.com/vibhor1102/monkeytype-local-analytics/issues/new/choose). See [privacy](PRIVACY.md) for what the extension stores and its limits.
