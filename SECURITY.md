# Security

[Report vulnerabilities privately on GitHub](https://github.com/vibhor1102/monkeytype-local-analytics/security/advisories/new). Include the affected version, reproduction steps, and possible impact. Don’t include passwords, browser profiles, or private backups.

For ordinary bugs, use [Issues](https://github.com/vibhor1102/monkeytype-local-analytics/issues/new/choose).
